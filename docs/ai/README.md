# AI Context — Common for Claude & Cursor

Read these files before making changes to the project:

1. **context.md** — Who, what, stack, structure, portfolio sections, key decisions.
2. **rules.md** — Design system and coding rules (8pt grid, typography, color, accessibility, etc.).
3. **verification.md** — What is implemented vs missing (HTML vs React).
4. **skills.md** — Which agent skills to prefer (frontend, Figma, rules, git).

**Using Claude or Cursor:** Instruct the AI to read **CONTEXT.md** (project root) and all files in **docs/ai/** before making changes. No tool-specific folders are required; this folder is the single source of truth.

Update files in **docs/ai/** when changing project context or rules.
