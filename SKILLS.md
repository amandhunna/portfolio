# Agent Skills for This Project

This file lists which **Cursor/Codex agent skills** to use when working on this repo. The AI is instructed via `.cursor/rules/agent-skills.mdc` to prefer these.

| Area | Skill / behavior | When to use |
|------|------------------|-------------|
| **Frontend** | Senior Frontend Staff Engineer | Architecture, refactors (e.g. extract sections), component API design, performance, code review |
| **Rules** | Create rule | Adding/editing Cursor rules, AGENTS.md, file-specific patterns |
| **Figma → code** | Code Connect | Mapping Figma components to React (Button, Card, Badge, Typography) |
| **Figma → code** | Create design system rules | Custom design rules for this project’s tokens and conventions |
| **Figma → code** | Implement design | Implementing Figma screens in React with 1:1 fidelity |
| **Editor** | Update Cursor settings | Theme, format-on-save, tab size, etc. |
| **Git** | Using Git | Repo setup, branches, commits |
| **Discover** | Find skills | “Is there a skill for X?” |
| **Custom** | Create skill | New project-specific skill (e.g. token usage, section structure) |

Figma-related skills require the Figma MCP server to be enabled.
